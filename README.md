# Sticky Notes App (iOS)

An iOS sticky notes application built using Swift and Xcode.  
Includes widget support for quick note access.

---

## Features
- Create and manage sticky notes
- Persistent storage using Core Data
- Widget extension for quick note viewing
- Clean UIKit-based interface

---

## Tech Stack
- Swift
- UIKit
- Core Data
- WidgetKit
- Xcode

---

## How to Run
1. Open `Sticky Notes App.xcodeproj` in Xcode
2. Select an iPhone simulator
3. Press Run (▶)
